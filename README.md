# HUJOOM

The published game: play it at https://dotnetdreamer.github.io/hujoom-game/

This repository holds the built files GitHub Pages serves, not the game's source: the game itself
(`index.html`, `assets/`, `basis/`), its optional packs (`packs/`) and its content, one folder per
asset version (`1/`), which the store apps download too. Every update
replaces this branch with a single commit.

Credits and licences: each version's `CREDITS.md`, `CREDITS-characters.md` and `CREDITS-vehicles.md`,
and each pack's `CREDITS.md`.
